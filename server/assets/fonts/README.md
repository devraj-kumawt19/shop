Invoice fonts derived from Google Fonts' Noto Sans Devanagari variable font:
https://github.com/google/fonts/tree/main/ofl/notosansdevanagari

The included static TTF instances use width 100 and weights 400/700. They support
Latin and Devanagari, including Hindi names and addresses, without a network font
request during invoice generation.
